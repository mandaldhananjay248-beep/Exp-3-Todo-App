# TaskFlow — Interactive To-Do App

TaskFlow is a modern, responsive to-do application built with HTML, CSS, and JavaScript to help students and beginners manage daily tasks in a clean and interactive way. The app combines a polished dashboard layout with task tracking, productivity statistics, and persistent browser storage so users can plan, update, and complete tasks efficiently.

## ✨ Features

- Add new tasks with a title, priority, category, and due date
- Mark tasks as completed or active
- Edit existing tasks without creating duplicates
- Delete individual tasks with confirmation
- Support for Low, Medium, and High task priorities
- Categorize tasks as Personal, Study, Work, or Other
- Search tasks by title in real time
- Filter tasks by status, category, and priority
- Sort tasks by newest first, oldest first, priority, or due date
- View due-date status such as overdue, due today, tomorrow, or upcoming
- Track total, completed, pending, and completion percentage statistics
- Clear all completed tasks with confirmation
- Toggle between dark and light themes
- Save task data with localStorage for persistence across refreshes
- Responsive interface for desktop, tablet, and mobile screens

## 🎨 UI & Design

TaskFlow uses a modern dark productivity-inspired interface with soft borders, rounded cards, subtle shadows, and a professional color palette. The layout is designed to feel clean and focused, while the light theme offers a comfortable alternative without changing the app’s structure or functionality. The design adapts responsively to smaller screens so the interface remains readable and easy to use on mobile devices.

1. Clone the repository to your local machine.
2. Open the project folder in VS Code.
3. Open the application in a browser.
4. You can also run the project with a local static server if preferred.

## 💡 How It Works

1. The user enters a task title and optional details such as priority, category, and due date.
2. JavaScript validates the task and adds it to the in-memory task list.
3. The task is rendered dynamically in the interface as a task card.
4. Users can complete, edit, search, filter, sort, and delete tasks.
5. The current task state is saved to localStorage so it remains available after refresh.
6. The dashboard updates automatically to reflect the latest task statistics and progress.
